# Программа анализа телеметрии и фиксации инцидентов
Программа анализа телеметрии и фиксации инцидентов

Этап 1

1. Назначение программы
   Программа предназначена для обработки и анализа телеметрических данных. Она выполняет парсинг входных записей, рассчитывает показатели динамики для компонентов, определяет их текущее состояние (INCREASE, DECREASE, NORMAL) и регистрирует инциденты на основе заданного условия с последующим расчетом статистики.
2. Описание варианта
   Вариант: №29 (базовый)
   Контролируемые компоненты: CPU1, CPU2, CPU3
   Производный показатель: Q = X[i] / X[i-1] - 1
   Критерий ALERT: INCREASE, если Q > 0.10; DECREASE, если Q < -0.10; иначе NORMAL. Компонент в ALERT, если он в состоянии INCREASE или DECREASE.
   Критерий инцидента: инцидент возникает, если ровно один из трёх компонентов находится в ALERT.
   Структура Incident: { long long time; int type; int count; float value; }
   Статистика журнала: интервалы между соседними инцидентами.
3. Описание инфраструктурных компонентов
   Язык программирования: C
   Среда разработки (IDE): Microsoft Visual Studio Community 2026
   Компилятор: MSVC (Microsoft Visual C++ Compiler)
4. Формат исходных данных
   Код компонента: CPU1, CPU2, CPU3
   Разделитель элементов: Точка с запятой (;)
   Порядок данных: компонент -> время -> значение
   Запись: одно измерение в строке
   Временная модель: T — порядковый номер отсчёта (целое число)
   Пример строки данных: CPU1;1;24.5
